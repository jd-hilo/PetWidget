HOW IT WORKS (short)
================================================================================

  1. Edge function creates message in `messages` table
  2. Edge function calls OneSignal REST API (silent/data push)
  3. iOS app wakes (or user opens app)
  4. App fetches pet + message from Supabase
  5. PetMessageDelivery builds Communication Notification with pet avatar

Silent push = no visible notification from OneSignal itself.
The avatar notification is always built locally in the app.

[ ] 1.2  APNs Auth Key — TEAM-SCOPED (.p8)

     You hit Apple's limit on keys and don't have .p8 files for older apps.
     That's OK. Here's what matters for Petmoji:

     WHAT A TEAM-SCOPED KEY IS
     -------------------------
     Apple's APNs Auth Keys (.p8) are always team-scoped: ONE key works for
     ALL apps under your Apple Developer team. You do NOT need a separate
     .p8 per app. You also do NOT need the old .p8 files from other apps
     to set up Petmoji.

     IF YOU ALREADY CREATED A NEW TEAM KEY FOR PETMOJI
     -------------------------------------------------
     [ ] You have the .p8 file downloaded (only available once at creation)
     [ ] You saved Key ID and Team ID somewhere safe
     [ ] You'll upload THIS same .p8 to OneSignal (Part 2)

     IF YOU HAVEN'T CREATED ONE YET
     ------------------------------
     1. Go to: https://developer.apple.com/account/resources/authkeys/list
     2. Click "+" to create a new key
     3. Name: e.g. "Petmoji APNs" or "Team APNs Shared"
     4. Check: "Apple Push Notifications service (APNs)"
     5. Continue → Register → Download .p8 immediately
     6. Record Key ID (10 chars) and Team ID

     IF YOU'RE AT THE 2-KEY LIMIT AND CAN'T CREATE ANOTHER
     -----------------------------------------------------
     Apple allows max 2 APNs Auth Keys per team. Options:

     A) Reuse an existing .p8 you still have on disk
        → Upload that file to OneSignal for Petmoji. One team key covers all apps.

     B) Revoke an unused/old key in Apple Developer → Keys
        → Only revoke if you're certain no other live app depends on it
        → Create a new key → download new .p8 → update OneSignal for ALL apps
          that used the revoked key

     C) You cannot recover a .p8 that was never downloaded
        → Revoking + creating new is the only path

     DO NOT confuse these with other Apple key types:
     - Sign in with Apple keys ≠ APNs keys
     - Developer ID / distribution certs ≠ APNs .p8

     PETMOJI DOES NOT NEED:
     - Per-app push certificates (.cer / .p12) if using .p8 via OneSignal
     - APNS_* secrets in Supabase (we use OneSignal instead)
